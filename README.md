# Steve's Coffee | Order Ahead & Rewards Pilot

The customer app is at `/` and the staff order screen is at `/staff`. See [DEPLOY.md](DEPLOY.md) for the Render setup and a staff test walkthrough.

## Run locally

Python 3.10 or later. There are no packages to install.

```bash
PILOT_CODE=local-test-access-code STAFF_PIN=local-staff-test-code ALWAYS_OPEN=1 TZ=America/Los_Angeles python3 server.py
```

Open http://localhost:8000 and use the local access code above. Use sample customer information. For the staff screen, also enter the separate local staff code. Use unique generated codes on Render.

## What the pilot does

Customers can create a test rewards account, order ahead for counter pickup, track the order, and see their points and reward activity. Staff uses the app's order screen to prepare orders and confirm pickups. The inherited sample program gives 10 welcome points and 1 point per whole dollar after the discount and before tax, when staff marks an order picked up. Sample rewards cost 50, 100, and 200 points. Cancellation returns points used on the order.

The sample menu lives in `menu.json`. Rewards and earning rules are in `server.py`. Pilot customer phone numbers are unverified and use a four-digit PIN. Orders use simulated Clover and are pay at pickup. Pilot points are stored in SQLite and cover orders placed through this app only.

## Settings

| Variable | Default locally | Purpose |
| --- | --- | --- |
| `PILOT_CODE` | Unset | Shared tester access code, generated by the Blueprint for Render |
| `STAFF_PIN` | Unset | Staff access code, generated separately by the Blueprint |
| `DB_PATH` | `steves.db` beside the server | SQLite file. Blueprint uses `/data/steves.db` on the disk |
| `PORT` | `8000` | HTTP listen port, supplied by Render when hosted |
| `TZ` | System time zone | Blueprint uses `America/Los_Angeles` |
| `STORE_OPEN` / `STORE_CLOSE` | `06:30` / `18:00` | Sample pickup hours, in the configured time zone |
| `ALWAYS_OPEN` | `0` | Set to `1` during staff testing to ignore sample hours |
| `PREP_MINUTES` | `10` | Minimum preparation time |
| `SLOT_CAPACITY` | `5` | Max active orders per five-minute slot |
| `CURBSIDE_ENABLED` | `0` | Set to `1` to try curbside check-in |

The Render pilot uses a single service with simulated Clover and generated credentials. Changing the pilot code invalidates previously issued pilot access cookies.
